## 1. Введение и цель работы

Целью работы является реализация полного пайплайна первичной обработки, очистки и группировки данных каталога Netflix (`netflix_data.csv`) с использованием инструментария **Apache PySpark**.

Все расчеты выполнены с использованием Spark DataFrame API, агрегаций, пивотирования и оконных функций.

---

## 2. Логика работы PySpark-скрипта

Скрипт выполняет обработку данных в несколько последовательных этапов:

1. **Конфигурация среды и инициализация Spark:**
   * Перед созданием `SparkSession` принудительно задаются переменные окружения (`SPARK_LOCAL_IP="127.0.0.1"`, `PYSPARK_PYTHON`) для корректного сетевого взаимодействия Java/Python воркеров в ОС Windows.

2. **Загрузка и строгая очистка данных:**
   * Данные читаются в текстовом формате без неявного автоопределения схем, после чего строки проходят фильтрацию регулярным выражением (`releaseYear.rlike("^[0-9]{4}$")`) для отсечения некорректно парсируемых строк.
   * Выполняется приведение типов (`integer`, `double`) и дедупликация по ключу `['title', 'releaseYear', 'imdbId']`.

3. **Задание 1 (Соотношение фильмов и сериалов):**
   * Для анализа жанров массив строк разворачивается с помощью `F.explode(F.split(...))` с очисткой от пробелов (`F.trim`).
   * Соотношение типов контента рассчитывается с помощью операции `.pivot("type", ["movie", "tv"])`.

4. **Задание 2 (Популярность жанров на IMDb):**
   * Группировка по жанрам с расчетом количества наименований (`count`), среднего рейтинга (`avg` с округлением до 2 знаков) и суммарного количества голосов (`sum`).

5. **Задание 3 (Динамика выпуска контента):**
   * Агрегация данных по годам выпуска за период с 2016 по 2025 гг.

6. **Задание 4 (Годовой прирост фильмов):**
   * Фильтрация контента типа `movie`, агрегация количества фильмов по годам.
   * Для расчете абсолютного прироста относительно предыдущего года используется оконная функция `Window.orderBy("releaseYear")` и функция сдвига `F.lag()`.

7. **Задание 5 (Поиск «Скрытых жемчужин»):**
   * Выборка фильмов/сериалов с `imdbAverageRating > 8.0` и `300 <= imdbNumVotes <= 10000`. Отсутствующие значения `availableCountries` заполняются значением `"NULL"` через `F.coalesce`.

## 3. Возникавшие сложности и их решение

1. **Таймаут воркеров `Python worker failed to connect back`:**
   * *Причина:* Ограничения локальной сети Windows при вызове `show()` / `toPandas()`.
   * *Решение:* Принудительная привязка адреса `127.0.0.1` в настройках `os.environ`.

2. **Ограничение оптимизатора Catalyst (`UNSUPPORTED_GENERATOR.NESTED_IN_EXPRESSIONS`):**
   * *Причина:* Попытка вложить `F.explode()` внутрь `F.trim()`.
   * *Решение:* Разделение операции на два последовательных `withColumn`.

3. **Ошибка типов данных при парсинге CSV (`CAST_INVALID_INPUT`):**
   * *Причина:* Попадание текста с запятыми в числовое поле `releaseYear`.
   * *Решение:* Отключение `inferSchema` и строгая предварительная фильтрация строк регулярными выражениями перед приведением к `integer`.
