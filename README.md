## Тема: Анализ пользовательских сессий и данных датасета Netflix

### 1. Описание работы и цель
В рамках данной работы я провела полный анализ данных по фильмам и сериалам с платформы Netflix на основе датасета `netflix_data.csv`. 

Главная цель работы - применить навыки работы с библиотекой Pandas в Python для очистки данных, фильтрации, вычисления статистики по годам и жанрам, а также наглядного вывода результатов в консоль.

---

### 2. Подготовка и очистка данных
Перед выполнением основных заданий я провела предварительную обработку данных:
- Загрузила датасет из CSV-файла в датафрейм Pandas.
- Привела числовые колонки (`releaseYear`, `imdbAverageRating`, `imdbNumVotes`) к соответствующим типам данных с помощью `pd.to_numeric()`.
- Убрала строки, где отсутствовали данные по жанрам (`genres`) и рейтингу IMDb (`imdbAverageRating`).
- Удалила дубликаты по комбинации полей `title`, `releaseYear` и `imdbId`.
- Разбила составные жанры (записанные через запятую) с помощью `.split()` и `.explode()`, чтобы корректно считать статистику по каждому отдельному жанру.

---

### 3. Ход выполнения заданий

#### Задание 1. Анализ соотношения фильмов и сериалов по жанрам и годам
- Для расчета по годам отфильтровала контент за последние 10 лет (с 2016 года) и составила сводную таблицу (pivot table) с количеством фильмов и сериалов.
- Для анализа жанров сгруппировала данные по каждому отдельному жанру, посчитала суммарное количество фильмов и сериалов и вывела топ-15 жанров по убыванию.

#### Задание 2. Популярность жанров на IMDb
- Сгруппировала контент по жанрам и посчитала для каждого три показателя: общее число фильмов/сериалов, средний рейтинг IMDb и общую сумму голосов.
- Отсортировала полученные данные по среднему рейтингу в порядке убывания и вывела топ-10 лучших жанров.

#### Задание 3. Динамика выпуска контента по годам и рейтинг
- Исключила некорректные и пустые значения годов выпуска.
- Посчитала общее количество выпущенных тайтлов и средний IMDb рейтинг для каждого года.
- Вывела итоговую статистику за последние 10 лет.

#### Задание 4. Анализ динамики прироста фильмов по годам
- Выделила из общего датасета только фильмы (`type == 'movie'`).
- Посчитала количество выпущенных фильмов за каждый год.
- С помощью функции `.shift(1)` посчитала количество фильмов в предыдущем году и вычислила абсолютный прирост (`title_count_growth`).
- Отсортировала результаты по значению прироста и вывела топ-10 лет с наибольшим ростом.

#### Задание 5. Поиск «Скрытых Жемчужин» (High Rating, Low Votes)
- Задала фильтрацию для поиска фильмов с очень высоким рейтингом (`imdbAverageRating > 8.0`) и относительно небольшим числом голосов (`imdbNumVotes` от 300 до 10 000).
- Вывела топ-10 таких тайтлов с наивысшим рейтингом.
